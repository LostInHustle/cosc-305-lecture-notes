# Budget Planning and Earned Value Management

## 1. Lecture Overview

Budget management helps a project team answer four important questions:

1. How much will the project cost?
2. When will the money be required?
3. Are we completing work according to schedule?
4. Are we spending more or less than planned?

Budget management begins during project planning and continues throughout project execution. During planning, the team estimates costs and creates a budget. During execution, the team compares planned performance with actual performance and takes corrective action when necessary.

Even if you do not plan to become a project manager, understanding budgets is useful. It helps you understand how managers make decisions, why they request certain information, and how project performance is evaluated.

# 2. Why Budget Planning Matters

A project can fail even when the technical work is good if the project does not have enough money at the correct time.

A proper budget helps the team:

1. Determine whether the project is financially realistic
2. Secure sufficient funding
3. Allocate labour and resources
4. Plan when payments must be made
5. Monitor spending during execution
6. Identify problems early
7. Explain project performance to sponsors and stakeholders
8. Decide whether corrective action is required

A budget is not only one total number. It should show how much money is needed, what the money will purchase, and when the money will be required.

# 3. Project Selection and Financial Evaluation

Before selecting a project, an organization may compare several investment options.

Common financial evaluation methods include the following.

## 3.1 Payback Period

The payback period measures how long it takes to recover the original investment.

A shorter payback period is generally preferred because the organization recovers its money sooner.

## 3.2 Rate of Return

The rate of return measures the financial benefit earned from an investment relative to its cost.

A higher rate of return generally indicates a more attractive project.

## 3.3 Net Present Value

Net Present Value converts future cash flows into their value today.

This is necessary because money available today is generally worth more than the same amount received in the future.

A project with a positive Net Present Value is generally financially attractive because its expected benefits exceed its current cost.

# 4. Cost Estimation Methods

Project managers can estimate costs using several approaches. The appropriate method depends on the available information, required accuracy, and amount of time available.

## 4.1 Resource Cost Estimation

This method identifies every required resource and calculates its cost.

For labour:

Resource cost equals hours required multiplied by the hourly rate

Example:

A software engineer works for 40 hours at 60 dollars per hour.

Cost equals 40 multiplied by 60

Cost equals 2400 dollars

The project manager repeats this calculation for employees, equipment, materials, software, contractors, and other resources.

This method can produce detailed estimates, but it requires time and reliable information.

## 4.2 Contractor Estimates

External contractors may provide bids or quotations for specific project work.

The project manager should consider:

1. The quoted amount
2. The exact work included
3. Payment dates
4. Contract conditions
5. Possible additional charges
6. The contractor’s reliability
7. The quality expected from the contractor

The cheapest offer is not automatically the best offer if it creates quality, schedule, or performance risks.

## 4.3 Analogous Estimation

Analogous estimation uses the cost of a previous similar project to estimate a new project.

Example:

If a similar website cost 25,000 dollars, that amount can provide an initial estimate for a new website with comparable size and complexity.

This approach is fast, but it may be inaccurate when the new project is significantly different.

## 4.4 Parametric Estimation

Parametric estimation uses a measurable unit and a known cost per unit.

Example:

Construction cost equals building area multiplied by cost per square foot

If a building has 2000 square feet and the estimated cost is 400 dollars per square foot:

Estimated cost equals 2000 multiplied by 400

Estimated cost equals 800,000 dollars

Other parameters may include:

1. Number of rooms
2. Number of users
3. Number of software features
4. Number of computers
5. Number of products
6. Number of labour hours

This method is useful when reliable historical data exist.

## 4.5 Bottom Up Estimation

Bottom up estimation begins with individual activities and resources.

The project team:

1. Estimates each activity
2. Estimates the resources required for each activity
3. Calculates the cost of each activity
4. Adds all activity costs together

Bottom up estimation usually provides high accuracy, but it takes more time than analogous or parametric estimation.

## 4.6 Activity Based Estimation

Activity based estimation assigns a budget to each project activity.

For example:

1. Requirements analysis costs 5000 dollars
2. System design costs 8000 dollars
3. Development costs 30,000 dollars
4. Testing costs 12,000 dollars
5. Deployment costs 5000 dollars

Total estimated cost equals 60,000 dollars

This approach makes it easier to monitor which activities are causing budget problems.

# 5. Cost, Time, Scope, and Quality

Project cost is connected to time, scope, and quality.

Increasing quality may require:

1. More skilled employees
2. More testing
3. Better materials
4. More reviews
5. Additional development time
6. More defect correction

Finishing work faster may require additional workers, overtime, or more expensive equipment.

Changing project scope may require more activities, labour, materials, and time.

The project manager must understand these relationships when changing the budget.

# 6. Project Reserves

A good project budget usually contains reserves. A reserve is money placed aside for uncertainty.

## 6.1 Contingency Reserve

A contingency reserve covers identified risks that may occur.

Examples include:

1. A supplier delivering materials late
2. A known technical problem requiring additional testing
3. An employee becoming temporarily unavailable
4. A possible increase in material prices

A contingency reserve is normally connected to known risks in the risk register.

## 6.2 Management Reserve

A management reserve covers unexpected work that was not included in the original project scope or risk analysis.

It is usually controlled by senior management or the project sponsor.

The project manager may need approval before using it.

## 6.3 Important Difference

Contingency reserve covers known uncertainty.

Management reserve covers unknown uncertainty or major unexpected changes.

# 7. Cash Flow Planning

A project may have an approved total budget without needing all the money immediately.

Cash flow planning identifies:

1. How much money is needed
2. When the money is needed

Example:

A five month project has a total budget of 100,000 dollars.

The expected monthly cash requirements are:

1. Month 1 requires 10,000 dollars
2. Month 2 requires 20,000 dollars
3. Month 3 requires 30,000 dollars
4. Month 4 requires 25,000 dollars
5. Month 5 requires 15,000 dollars

The total is 100,000 dollars.

The organization does not necessarily need to place the complete 100,000 dollars in the project account at the beginning. It needs to make each amount available before the related payment is due.

This prevents money from remaining unused when it could be invested or used by another project.

# 8. Budget Timeline and Funding

The budget timeline shows expected spending over the life of the project.

The funding curve represents money made available to the project.

The spending curve represents money paid for project work.

Funding should be available before the project must make a payment. If the required money has not arrived, the project may face a cash shortage even when the total budget has been approved.

Therefore:

Available funding should remain greater than or equal to required spending.

# 9. Budget Monitoring During Execution

Planning creates the budget baseline.

The budget baseline is the approved version of the project budget used to measure performance.

During execution, actual results may differ from the baseline because:

1. Work takes longer than expected
2. Labour rates change
3. Material prices change
4. Activities finish early or late
5. Employees require overtime
6. Defects require correction
7. Scope changes
8. Productivity differs from expectations

The project manager must compare planned work, completed work, and actual spending.

Earned Value Management provides a structured method for making these comparisons.

# 10. Earned Value Management

Earned Value Management integrates scope, schedule, and cost.

It uses three main values:

1. Planned Value
2. Earned Value
3. Actual Cost

These values are measured at a specific point during the project.

# 11. Planned Value

Planned Value is the approved budget for the work that should have been completed by the measurement date.

Abbreviation: PV

Older term: Budgeted Cost of Work Scheduled

Question answered:

How much budgeted work should be complete by now?

Example:

The plan states that five activities should be complete by today. Their total approved budget is 1000 dollars.

PV equals 1000 dollars

Planned Value is based on the approved plan. It is not the amount actually spent.

# 12. Earned Value

Earned Value is the approved budget value of the work that has actually been completed.

Abbreviation: EV

Older term: Budgeted Cost of Work Performed

Question answered:

According to the project budget, how much should the completed work have cost?

Example:

The team planned to complete five activities but actually completed six. According to the approved budget, the six completed activities should cost 1100 dollars.

EV equals 1100 dollars

Earned Value uses budgeted rates, not actual spending.

# 13. Actual Cost

Actual Cost is the amount actually spent on the completed work.

Abbreviation: AC

Older term: Actual Cost of Work Performed

Question answered:

How much did the completed work actually cost?

Example:

The six completed activities should have cost 1100 dollars according to the budget. However, the project actually spent 1200 dollars.

AC equals 1200 dollars

# 14. Understanding PV, EV, and AC

Use the following questions to remember the three values.

1. PV asks what work should be complete and what that work was budgeted to cost.
2. EV asks what work is actually complete and what that work was budgeted to cost.
3. AC asks what the completed work actually cost.

PV and EV use the approved budget.

AC uses real spending data.

# 15. Earned Value Example

Suppose a project has the following information at the end of Week 5:

PV equals 1000 dollars

EV equals 1100 dollars

AC equals 1200 dollars

Interpretation:

1. The project planned to complete 1000 dollars of work.
2. The project actually completed 1100 dollars of budgeted work.
3. The completed work actually cost 1200 dollars.

The project completed more work than planned, but it spent more than the budgeted value of that work.

Therefore, the project is ahead of schedule but over budget.

# 16. Schedule Variance

Schedule Variance compares completed work with planned work.

Formula:

SV equals EV minus PV

Interpretation:

1. SV greater than zero means the project is ahead of schedule.
2. SV equal to zero means the project is on schedule.
3. SV less than zero means the project is behind schedule.

Using the example:

SV equals 1100 minus 1000

SV equals 100 dollars

The positive result means the project is ahead of schedule in earned value terms.

Schedule Variance is expressed as a monetary value, even though it describes schedule performance.

# 17. Cost Variance

Cost Variance compares the budgeted value of completed work with its actual cost.

Formula:

CV equals EV minus AC

Interpretation:

1. CV greater than zero means the project is under budget.
2. CV equal to zero means the project is exactly on budget.
3. CV less than zero means the project is over budget.

Using the example:

CV equals 1100 minus 1200

CV equals negative 100 dollars

The negative result means the project is over budget.

# 18. Schedule Performance Index

The Schedule Performance Index expresses schedule performance as a ratio.

Abbreviation: SPI

Formula:

SPI equals EV divided by PV

Interpretation:

1. SPI greater than 1 means the project is ahead of schedule.
2. SPI equal to 1 means the project is on schedule.
3. SPI less than 1 means the project is behind schedule.

Using the example:

SPI equals 1100 divided by 1000

SPI equals 1.10

The project is progressing at approximately 110 percent of the planned rate.

# 19. Cost Performance Index

The Cost Performance Index measures cost efficiency.

Abbreviation: CPI

Formula:

CPI equals EV divided by AC

Interpretation:

1. CPI greater than 1 means the project is under budget.
2. CPI equal to 1 means the project is exactly on budget.
3. CPI less than 1 means the project is over budget.

Using the example:

CPI equals 1100 divided by 1200

CPI equals approximately 0.92

This means the project earns approximately 92 cents of budgeted value for every dollar spent.

# 20. Quick Interpretation Rules

For schedule performance:

1. Positive SV is good.
2. Negative SV is a warning.
3. SPI above 1 is good.
4. SPI below 1 is a warning.

For cost performance:

1. Positive CV is good.
2. Negative CV is a warning.
3. CPI above 1 is good.
4. CPI below 1 is a warning.

Remember:

Variance uses subtraction.

Performance index uses division.

# 21. Budget at Completion

Budget at Completion is the total approved budget for the complete project.

Abbreviation: BAC

Example:

If the approved total project budget is 100,000 dollars:

BAC equals 100,000 dollars

The budget timeline should eventually reach the BAC at project completion.

# 22. Estimate to Complete

Estimate to Complete predicts how much additional money will be required to finish the remaining work.

Abbreviation: ETC

If current cost performance problems are not expected to continue:

ETC equals BAC minus EV

Example:

BAC equals 100,000 dollars

EV equals 80,000 dollars

ETC equals 100,000 minus 80,000

ETC equals 20,000 dollars

This assumes that the remaining work will follow the original budget.

If the current cost efficiency is expected to continue:

ETC equals BAC minus EV, divided by CPI

Example:

BAC equals 100,000 dollars

EV equals 80,000 dollars

CPI equals 0.80

ETC equals 20,000 divided by 0.80

ETC equals 25,000 dollars

Because the project is experiencing poor cost efficiency, it may require 25,000 dollars instead of 20,000 dollars to finish.

# 23. Estimate at Completion

Estimate at Completion predicts the total final cost of the project.

Abbreviation: EAC

One common formula is:

EAC equals AC plus ETC

Example:

AC equals 85,000 dollars

ETC equals 25,000 dollars

EAC equals 85,000 plus 25,000

EAC equals 110,000 dollars

The project is therefore forecast to finish 10,000 dollars above the original 100,000 dollar budget.

Another common formula, when current cost performance is expected to continue, is:

EAC equals BAC divided by CPI

# 24. Variance at Completion

Variance at Completion compares the original budget with the expected final cost.

Abbreviation: VAC

Formula:

VAC equals BAC minus EAC

Interpretation:

1. Positive VAC means the project is expected to finish under budget.
2. Zero VAC means the project is expected to finish exactly on budget.
3. Negative VAC means the project is expected to finish over budget.

Example:

BAC equals 100,000 dollars

EAC equals 110,000 dollars

VAC equals 100,000 minus 110,000

VAC equals negative 10,000 dollars

The project is expected to finish 10,000 dollars over budget.

# 25. Complete Worked Example

A project has the following information:

PV equals 50,000 dollars

EV equals 45,000 dollars

AC equals 60,000 dollars

BAC equals 200,000 dollars

## Schedule Variance

SV equals EV minus PV

SV equals 45,000 minus 50,000

SV equals negative 5000 dollars

The project is behind schedule.

## Cost Variance

CV equals EV minus AC

CV equals 45,000 minus 60,000

CV equals negative 15,000 dollars

The project is over budget.

## Schedule Performance Index

SPI equals EV divided by PV

SPI equals 45,000 divided by 50,000

SPI equals 0.90

The project is progressing at approximately 90 percent of the planned rate.

## Cost Performance Index

CPI equals EV divided by AC

CPI equals 45,000 divided by 60,000

CPI equals 0.75

The project earns only 75 cents of budgeted value for every dollar spent.

## Estimate at Completion

Assume the current cost efficiency continues.

EAC equals BAC divided by CPI

EAC equals 200,000 divided by 0.75

EAC equals approximately 266,667 dollars

## Variance at Completion

VAC equals BAC minus EAC

VAC equals 200,000 minus 266,667

VAC equals approximately negative 66,667 dollars

The project is forecast to finish approximately 66,667 dollars over budget if current performance continues.

# 26. Zero Earned Value with Actual Spending

An activity may have the following values:

EV equals zero

AC equals 2000 dollars

This usually means the project has spent 2000 dollars on the activity, but no completed work has been officially recognized.

Possible reasons include:

1. The activity has started but is not complete.
2. The project uses a rule that awards value only after completion.
3. Materials were purchased before the activity began.
4. Employees recorded hours, but no accepted deliverable was produced.
5. The work was completed but not approved.
6. Progress data were entered incorrectly.

The project manager should check the completion rules, invoices, timesheets, deliverable status, and approval records.

# 27. Monitoring and Corrective Action

Earned Value Management should be performed regularly, not only at the end of the project.

At each reporting date, the project manager should:

1. Record PV
2. Measure completed work
3. Calculate EV
4. Record AC
5. Calculate SV and CV
6. Calculate SPI and CPI
7. Update ETC, EAC, and VAC
8. Identify activities causing the variance
9. Assign an owner to each corrective action
10. Define evidence that shows whether the action succeeded
11. Communicate the results to stakeholders

# 28. Possible Corrective Actions

If the project is behind schedule or over budget, possible actions include:

1. Reassigning employees to critical activities
2. Reducing unnecessary work
3. Correcting productivity problems
4. Renegotiating supplier or contractor costs
5. Improving quality controls to reduce repeated work
6. Using contingency reserve for an identified risk
7. Requesting approval to use management reserve
8. Moving budget from a lower priority activity
9. Changing the schedule
10. Requesting additional funding
11. Reducing scope with sponsor approval
12. Improving the accuracy of progress reporting

The project manager should not cut costs in ways that damage critical quality, safety, or project requirements.

# 29. Corrective Action Example

Problem:

CPI equals 0.80 because testing defects are creating repeated work.

Action:

The project manager assigns the testing lead to introduce an earlier code review and defect screening process.

Owner:

Testing lead

Evidence of success:

1. Weekly defect count decreases
2. Repeated testing hours decrease
3. CPI improves toward 1
4. No critical quality requirements are removed

This is stronger than simply writing “reduce spending” because it identifies the problem, action, owner, and measurable result.

# 30. Key Formula Summary

PV means the budgeted value of work planned.

EV means the budgeted value of work completed.

AC means the actual cost of completed work.

SV equals EV minus PV

CV equals EV minus AC

SPI equals EV divided by PV

CPI equals EV divided by AC

ETC estimates the remaining cost.

EAC estimates the final total cost.

VAC equals BAC minus EAC

# 31. Final Exam Tips

1. PV concerns planned work.
2. EV concerns completed work valued using the approved budget.
3. AC concerns actual spending.
4. Positive SV means ahead of schedule.
5. Negative SV means behind schedule.
6. Positive CV means under budget.
7. Negative CV means over budget.
8. SPI above 1 is favourable.
9. CPI above 1 is favourable.
10. BAC is the original total approved budget.
11. EAC is the predicted final cost.
12. VAC shows the expected difference between BAC and EAC.
13. Always interpret the result after completing a calculation.
14. Use schedule and cost measurements together because a project can be ahead of schedule but over budget.
15. A reserve is not unrestricted money. Its use should follow project governance and approval rules.

# 32. Main Takeaway

Budget management connects planning with project control.

First, estimate the resources and costs. Next, determine when funding is required. During execution, compare Planned Value, Earned Value, and Actual Cost. Then use variances, performance indexes, and forecasts to identify problems and choose corrective actions.

The purpose is not only to calculate numbers. The purpose is to use those numbers to make better project decisions.
